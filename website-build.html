Architectural Decisions

Technical Stack Breakdown

Every architectural decision documented with rationale and trade-off analysis.

Zero-Framework Frontend

HTML5 • CSS3 Grid/Flexbox • ES6+ JS

Rationale: Modern React/Next.js/Vue frameworks ship 300KB–2MB of runtime JavaScript before rendering text. By utilizing semantic HTML5 and CSS Custom Properties, we achieve instantaneous DOM readiness without hydration lag.

Zero Dependencies No Hydration Lag

Edge Hosting & CDN

GitHub Pages • Cloudflare Anycast

Rationale: Static files are replicated across 300+ edge locations worldwide. Requests are served from the closest edge node with TLS 1.3 and Brotli level 11 compression, achieving sub-20ms TTFB across North America, Europe, and Asia.

Anycast Routing Brotli Compression

DevSecOps & CI Pipeline

GitHub Actions Workflow

Rationale: Automated validation workflows run on every pull request. Automated Lighthouse CI runs headless Chrome tests to prevent performance regressions or accessibility infractions before code is merged.

GitHub Actions Automated Audits

Zero Attack Surface

Static Immutability • Strict CSP

Rationale: No backend server operating system to patch, no PHP/Node server daemon to compromise, no SQL database to inject. All assets are cryptographically hashed and delivered over HTTPS with strict security headers.

Zero SQLi / XSS A+ Security Grade

FinOps Unit Economics

$0 Monthly Hosting Operational Cost

Rationale: Enterprise architects preach cost stewardship. Running personal portfolios on idle $40/mo Kubernetes clusters or dynamic cloud app services violates FinOps principles. Serverless static edge hosting incurs strictly zero operational expense.

$0/Month TCO FinOps Principles

Green Cloud Sustainability

< 0.04g CO2 per Pageview

Rationale: Ultra-lean asset footprints (under 100KB total transferred per page) consume 95% less electrical power on client CPU decoders and edge network repeaters than bloated client-side SPA architectures.

Green Web Certified 95% Energy Cut
